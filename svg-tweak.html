操作提示

拖动 移动 · Shift+拖动 锁定方向
Shift+点击 加选 / 减选
框选只选“完全框住”的；Alt+框选 = 碰到就算
Alt+点击 选中组里的单个元素
方向键 微调 1px · Shift+方向键 10px
双击 改文字 · Delete 删除
拖框上方小圆 = 旋转（Shift 15°一档）· 拖方块 = 缩放
组 / 多选也能拖框缩放：只变形状，线宽不变
Ctrl+G 组合 · Ctrl+Shift+G 解组
Ctrl+C 复制 · Ctrl+V 粘贴 · Ctrl+X 剪切
Ctrl+] 上移一层 · Ctrl+[ 下移一层
Ctrl+Shift+] 置顶 · Ctrl+Shift+[ 置底
P 画线（正交/手绘可切）· 双击或回车结束
R 画矩形：拖动，Shift 正方形
T 添加文字：点一下就写
路径/多边形选中就有节点：拖蓝方块改形状，拖橙方块缩放，拖上方圆圈旋转
节点拖动：锁轴；「连锁」开着时整条腿平移（想改长度就点 连锁 关掉）
Ctrl 临时反向、Alt 完全自由拖
N 显示/隐藏节点 · 双击线段 = 加节点 · 选中节点 Delete = 删节点
Ctrl+滚轮 缩放 · Esc 取消选择

说明

直接编辑 SVG 原始元素，不重绘、不包一层。
导出的文件保留原有 id 和结构，AI 可以接着改。
AI 协作 实验
API 连接设置

网页非空项优先，空项读取同目录 ai-config.js。点击「保存配置」可把当前有效配置（含 Key）写入文件，首次请选择网页同目录的 ai-config.js；本次打开后续保存会写回该文件。Key 不自动存入浏览器，配置文件为明文，请勿分享。

SVG、对话、参考图和可选画布截图会发送到配置的服务，服务需允许浏览器跨域请求。

检测会发送一次极短文本请求，可能产生少量费用；不发送图或聊天，也不验证改图或图片能力。

AI 始终修改当前画布，包含你的手动调整。
修改范围

可拖入 AI 输入区 / 粘贴 · 仅供 AI 参考，不加入画布；需模型支持图片。

按阶段显示进度；接口不提供完成百分比，耗时取决于模型与图的大小。
